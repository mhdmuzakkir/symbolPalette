Adding Symbols

To add new symbols:

  1. Open your root folder (e.g. G:/My Drive/mushafproject/symbols)
  2. Create a new folder for the category (e.g. lines, ornaments, accents)
  3. Drop SVG files into that folder
  4. Click ↻ Refresh in the panel

File rules:

  • Only .svg files are loaded
  • File name becomes the symbol name
  • Sub-folders are treated as categories

Numbers:

Put ayah number SVGs in a numbers/ folder at the root level.
