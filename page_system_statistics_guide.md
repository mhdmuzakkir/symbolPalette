# How to Extract Ayah Numbers from `page_system_statistics.json`

## File Purpose
This JSON contains complete Mushaf statistics for all 6 counting systems across all 604 pages. It is generated by the MushafQuery app.

## Top-Level Structure

```json
{
  "metadata": {...},
  "mushaf_totals": {...},
  "surah_statistics": [...],
  "page_statistics": [...]
}
```

## Key Sections

### 1. `mushaf_totals`
Total ayah count per system:
```json
{
  "al_kufi": 6236,
  "al_madani_al_awwal": 6214,
  "al_madani_al_akhir": 6214,
  "al_makki": 6220,
  "al_basri": 6204,
  "al_dimashqi": 6226
}
```

### 2. `surah_statistics` (114 entries)
Per-surah data including ayah counts for each system:
```json
{
  "surah_number": 2,
  "surah_name": "Al-Baqarah",
  "start_page": 2,
  "end_page": 49,
  "system_ayah_counts": {
    "al_kufi": 286,
    "al_madani_al_awwal": 285,
    ...
  }
}
```

### 3. `page_statistics` (604 entries) — **Main extraction target**
Each page entry contains:
```json
{
  "page_number": 100,
  "surahs": [4],
  "first_line": "...",
  "last_line": "...",
  "systems": {
    "al_kufi": {
      "verse_range": "4:135-4:140",
      "ayah_count": 6
    },
    "al_madani_al_awwal": {
      "verse_range": "4:134-139",
      "ayah_count": 6
    }
  }
}
```

## How to Parse `verse_range`

The `verse_range` string follows one of two formats:

### Format A: Single Surah
`"surah:first_ayah-last_ayah"`

Example: `"4:135-140"` means Surah 4, ayahs 135 through 140.

**Extraction logic:**
```python
def parse_range(range_str):
    # "4:135-140" -> surah=4, start=135, end=140
    surah_part, ayah_part = range_str.split(':')
    surah = int(surah_part)
    start, end = map(int, ayah_part.split('-'))
    return [(surah, a) for a in range(start, end + 1)]
```

### Format B: Multi-Surah Page
`"start_surah:start_ayah-end_surah:end_ayah"`

Example: `"89:27-90:20"` means from S89 ayah 27 to S90 ayah 20.

**Extraction logic:**
```python
def parse_range(range_str):
    # "89:27-90:20"
    left, right = range_str.split('-')
    start_surah, start_ayah = map(int, left.split(':'))
    end_surah, end_ayah = map(int, right.split(':'))
    
    ayahs = []
    if start_surah == end_surah:
        for a in range(start_ayah, end_ayah + 1):
            ayahs.append((start_surah, a))
    else:
        # From start_surah:start_ayah to end of start_surah
        # (you need surah total ayahs from surah_statistics)
        # Then middle surahs (all ayahs)
        # Then end_surah:1 to end_ayah
        pass  # see full example below
    return ayahs
```

## Complete Python Extraction Example

```python
import json

with open('page_system_statistics.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# Build surah total ayah lookup from the file itself
surah_totals = {}
for s in data['surah_statistics']:
    sn = s['surah_number']
    surah_totals[sn] = {
        'name': s['surah_name'],
        'kufi_total': s['system_ayah_counts']['al_kufi']
    }

def extract_page_ayahs(page_entry, system_key='al_makki'):
    """Extract all (surah, ayah) tuples for a given system on this page."""
    range_str = page_entry['systems'][system_key]['verse_range']
    
    # Check if multi-surah (has two colons)
    if range_str.count(':') == 2:
        # "89:27-90:20"
        left, right = range_str.split('-')
        start_s, start_a = map(int, left.split(':'))
        end_s, end_a = map(int, right.split(':'))
        
        ayahs = []
        if start_s == end_s:
            for a in range(start_a, end_a + 1):
                ayahs.append((start_s, a))
        else:
            # Start surah: from start_a to its total
            start_total = surah_totals[start_s]['kufi_total']
            for a in range(start_a, start_total + 1):
                ayahs.append((start_s, a))
            # Middle surahs (all ayahs)
            for s in range(start_s + 1, end_s):
                s_total = surah_totals[s]['kufi_total']
                for a in range(1, s_total + 1):
                    ayahs.append((s, a))
            # End surah: from 1 to end_a
            for a in range(1, end_a + 1):
                ayahs.append((end_s, a))
        return ayahs
    else:
        # Single surah: "4:135-140"
        surah_part, ayah_part = range_str.split(':')
        surah = int(surah_part)
        start, end = map(int, ayah_part.split('-'))
        return [(surah, a) for a in range(start, end + 1)]

# Example: Get all Makki ayahs on page 100
page_100 = data['page_statistics'][99]  # index 99 = page 100
makki_ayahs = extract_page_ayahs(page_100, 'al_makki')
print(f"Page 100 has {len(makki_ayahs)} Makki ayahs:")
for s, a in makki_ayahs:
    print(f"  Surah {s}, Ayah {a}")
```

## Important Notes

1. **`ayah_count` vs actual extracted count**: `ayah_count` is pre-computed and should match `len(extract_page_ayahs(...))`. If it doesn't, there's a parsing bug.

2. **Ayah numbers restart per surah**: Surah 2 ayah 1 and Surah 3 ayah 1 are different ayahs. Always treat `(surah, ayah)` as a pair.

3. **The Kufi range is authoritative for page boundaries**: The physical page always contains the same text. Other systems just renumber the same ayahs. A system with fewer ayahs on a page means some Kufi ayahs were merged; more ayahs means some were split.

4. **Systems included**: `al_kufi`, `al_madani_al_awwal`, `al_madani_al_akhir`, `al_makki`, `al_basri`, `al_dimashqi`

5. **File location**: Generated next to the EXE (or in project root when running as script) as `page_system_statistics.json`.
